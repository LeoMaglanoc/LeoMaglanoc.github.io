# Archived Arnold policy experiments

The released game in this directory is a human-playable GZDoom deathmatch. It
does not load a model, ONNX Runtime, policy state, observation readback, or a
native RL bridge.

The historical Arnold reproduction, export, and validation material remains in
`../tools/`, `../docs/`, `../models/`, and `../engine/patches/`. Those files are
kept for research provenance only and are not part of the browser game runtime.
