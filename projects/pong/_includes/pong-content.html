What is happening?

      
A PPO agent controls the right paddle and chooses up, stay, or down from the current game state.

    

    

      
Observation

      
Ball position and velocity, plus the agent paddle position. Every value is normalized to approximately −1…1.

    

    

      
Training & deployment

      
Stable-Baselines3 / PyTorch → ONNX → ONNX Runtime Web. Inference happens entirely inside the browser.
