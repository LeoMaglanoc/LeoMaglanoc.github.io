# Browser solver assets

`nlp`, `pack`, `bounds`, and `decode` are gzipped CasADi function serializations created by `tools/export_runtime.py` from the pinned original whole-body RNEA OCP. Pinocchio symbolic rigid-body calculations are embedded offline. Runtime JavaScript supplies state, commands, schedule parameters and a primal initialization; IPOPT computes feedback controls in a worker; Fatrop runs the numerical transfer fixture.

`native-fixture.json` is an exact numerical transfer fixture. `seeds.json` contains gait-specific nominal feasible primal guesses generated by `export_seeds.py`, not playback controls. `deployment.json` defines dimensions, input offsets and graph metadata. Browser solver options are in `runtime.js`; native export options are separately recorded.

`vendor/casadi` is an unmodified subset of npm `@casadi/casadi-wasm` 3.8.1: the core JS/WASM, Fatrop, IPOPT, MUMPS and BLASFEO side modules, plugin manifest, package metadata and complete license directory. Original sources/build instructions are linked in THIRD_PARTY_NOTICES.md. `load-casadi.js` adapts the package's CommonJS loader in the worker with locally fetched pinned files. It does not accept arbitrary code or user-supplied module paths.

Regenerate symbolic assets using the Docker commands in the project README. `npm test` checks real native/WASM output agreement, as well as worker lifecycle and mapping contracts. Browser setup currently takes approximately ten seconds and feedback solves can take seconds; this is experimental slow motion.

`finalization-compat.js` scopes explicit ownership to the package wrapper without modifying vendor bytes. It avoids a reproduced SWIG automatic-finalizer heap-corruption bug. Owned runtime handles are deleted explicitly, and the client recycles the worker after 128 successful solves. Run `node --expose-gc tests/feedback-check.mjs` to exercise GC between actual physics-feedback solves.
