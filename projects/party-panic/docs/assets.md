# Asset and source provenance

v0.2 uses original procedural geometry and character models. No Quaternius packs,
reference maps, models, sounds or branding have been copied.

- PlayCanvas engine 2.23.3: existing npm dependency, MIT; lockfile pins exact version.
- Official third-person-controller.mjs: inspected from playcanvas/engine main on
  2026-10-19, MIT license inspected. Engineering reference only; no source transplant.
- Freerun 08 and Blaster Range: playcanvas/prompts prompt.md and README source inspected
  2026-10-19. They are measured specifications, not reusable game source.
  Runtime pages fetched; subsequent runtime observations must be recorded separately.
- Existing Ammo distribution/provenance remains public/ammo/SOURCE.md and LICENSE.
- Existing local font licenses remain public/fonts/*LICENSE.txt.

References: https://github.com/playcanvas/engine/blob/main/scripts/esm/third-person-controller.mjs,
https://github.com/playcanvas/prompts/tree/main/freerun-08,
https://github.com/playcanvas/prompts/tree/main/blaster-range.

Laser Tag's arena, blaster primitives, spawn pads, grid, tracers and shield indicator are
original procedural geometry. Short cues are generated by Web Audio oscillators. Solo
bots use handwritten input policies and navigation; no models/weights or third-party
character/weapon assets are downloaded. Gameplay recordings depict this original project.

## v0.3 source adaptations (2026-10-19)

- [Wobble Rush 3D](https://github.com/code-yeongyu/wobble-rush-3d/tree/b395e4a91ebdfb829533b1ae6beda244371658a3),
  commit `b395e4a91ebdfb829533b1ae6beda244371658a3`, MIT © 2026 YeonGyu Kim.
  Adapted algorithms: movement.ts momentum decay and stumble ramp; simulation.ts
  variable gravity, committed dive, blended impact and shortest-arc turning;
  scene.ts camera half-life damping. Controller rewritten for host Ammo ownership;
  no Three.js world/collision code, assets or network code copied.
- [Blockyard](https://github.com/Potrock/blockyard/tree/a8cce1caeda1fbec9c913030f14ed3435c6d8d20),
  commit `a8cce1caeda1fbec9c913030f14ed3435c6d8d20`, MIT © 2026 Patrick Blais.
  Adapted tagger.shared/server/client energy, rate and monotonic shot-sequence
  algorithms and blockfront/hits.ts distinct damage/elimination feedback design.
  New pure weapon rules use Party Panic numbers and host-owned hits. No voxel
  engine, Rust, assets, weapon names, backend or asset pipeline copied.
- Native [PlayCanvas third-person controller](https://github.com/playcanvas/engine/blob/982f5a68b248c66e7cd382e61de83acb22686249/scripts/esm/third-person-controller.mjs),
  commit `982f5a68b248c66e7cd382e61de83acb22686249`: studied separate touch control
  ownership, camera-relative movement and padded collision probe. Implementation
  independently written against existing Party Panic API. Existing PlayCanvas
  dependency license remains unchanged.

Full MIT permissions/warranty notices for both adapted upstream projects are
retained verbatim in `evidence/v03-baseline/wobble-rush-LICENSE.txt` and
`evidence/v03-baseline/blockyard-LICENSE.txt`. They accompany source distribution.
No new third-party assets were imported; all new effects use existing primitives
and independently synthesized audio. No Fall Guys or Star Wars assets.

The two MIT notices also ship with production builds under
`public/licenses/{wobble-rush,blockyard}-MIT.txt` (served as `licenses/…`).
