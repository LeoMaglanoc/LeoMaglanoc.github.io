Tracking accuracy and mapping accuracy

        
Synthetic living-room benchmark · noisy RGB-D · four trajectories. The viewer shows kt0; the table includes every sequence and the equal-weight mean. All reconstruction and evaluation run offline.

        
Accuracy measures reconstructed surface → full GT triangles. Completeness measures the fixed clean-depth visible GT → reconstruction. Both mappers use the same graph frames. Estimated maps use the trajectory's rigid alignment, with no scale fit or independent ICP. Scores use unsimplified master meshes.

        
RTAB's RGB view uses projected UV textures; TSDF uses fused RGB vertex colors. Geometry and error views share the same simplified surface. UV texturing may omit triangles without RGB coverage.

        

        
Clean depth and known poses

        
Clean depth with known poses measures fusion plus the small depth/reference residual. Noisy depth adds sensor noise; estimated poses add tracking error. These differences are diagnostic and need not add linearly.
