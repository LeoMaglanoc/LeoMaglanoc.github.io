# Ask Leo knowledge-base audit

`_data/assistant_kb.yml` is a deliberately small, public-only evidence set. It is not a crawl of the site and it is the only hand-maintained assistant knowledge base.

## Sources used

- `assets/json/resume.json` for structured roles, education, and BMW details.
- `_pages/about.md` and `_data/homepage.yml` for the current homepage positioning and current featured-project descriptions.
- `_projects/*.md` and the browser-demo READMEs for project-specific technical facts.

## Boundaries

- No private details, CV parsing, web search, GitHub live retrieval, or unreviewed project claims are exposed.
- Skill claims are explicit and point to evidence record IDs in the `skills` index; the model is instructed not to infer additional skills.
- Links in source chips are retrieval provenance. They are not citations generated by the language model.
