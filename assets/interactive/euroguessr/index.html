INSIDE THE AI

A little geographic intuition.

ImageNet MobileNetV3-Small turns the same photograph you see into a visual embedding. We compare a trained geographic head against image retrieval, and select the method using spatial validation.

The AI receives normalized pixels only. Ground-truth coordinates are used after you submit. This is a casual static game, so its downloadable answer pack is inspectable; it is not a secure competition.
